About BrainBuzz

A small web-based quiz game that makes reviewing HTML active and fun.

Project Rationale

Filipino internet users aged 16 to 64 spend an average of 8 hours and 52 minutes online daily, the highest among 17 surveyed countries and well above the global average of 6 hours and 38 minutes (DataReportal, 2025). For IT students, much of this time goes to passive browsing instead of productive learning, even though HTML is the foundation of web development and a core skill in the degree program.

Many students struggle with HTML basics such as definitions, tag purposes, and form elements because they rely on reading notes without enough interactive practice. Without active review, they may memorize definitions briefly but not understand how and when to use each element.

BrainBuzz is a small web-based quiz game that helps 2nd-year IT students review HTML lessons from CIT16233Z. It focuses on three topics, gives instant feedback, and runs in any web browser for free.

Game-based learning improves student engagement, retention, and critical thinking compared to passive study (Mao et al., 2022). Retrieving information through quizzes strengthens memory more than rereading (Pastötter & Bäuml, 2014).

Project Features

Users pick a topic, answer 10 multiple-choice questions against a countdown timer, and see their score and best score at the end.

Game and Progress Features

  • Timer and scoring: a countdown timer, a running score, and instant right or wrong feedback after each answer.
  • Best score per topic: saved automatically in browser LocalStorage and shown on the topic cards.
  • Clear Scores: one button resets all saved scores.
  • Retry: any quiz can be retaken as many times as needed.
  • Responsive design: works on phones, tablets, and computers.

Technical Requirements

Components used to build BrainBuzz
ComponentDescription
Hardware Standard personal computer or laptop with at least 4 GB RAM, keyboard, mouse, and internet connection, used for designing, coding, testing, and running the website.
Software Visual Studio Code is used exclusively for writing and editing the HTML, CSS, and JavaScript files. Google Chrome or Mozilla Firefox is used for testing.
HTML5 Creates the page structure: quiz questions, buttons, game sections, score displays, and all visible content.
CSS3 Handles styling, colors, layout, animations, and responsive design using the viewport principle taught in class.
JavaScript Powers interactivity: loading quizzes, checking answers, calculating scores, running timers, and saving progress.
Storage Browser LocalStorage API saves scores on the user's device. No database, server, or backend code is required.
Project Files index.html, style.css, script.js, and questions.js (the question data for all topics).

Anticipated Challenges

Content Accuracy & Alignment

Ensuring all definitions, tag purposes, and concepts match exactly what is taught in the course materials, so the tool serves as a valid study aid aligned with exam coverage.

Consistent Cross-Browser Behavior

Making sure JavaScript, LocalStorage, and the responsive layout work identically across Chrome, Firefox, and Edge, since web page display varies across browsers.

Balanced Difficulty Levels

Designing questions that are accessible to beginners early in the semester while still being useful as students advance into topics such as linking pages, website structure, and forms.
